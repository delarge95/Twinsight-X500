01

Capacidades

Modelo y trazabilidad

Representación interactiva del Holybro X500 V2 con 28 piezas canónicas, 30 anchors de escena y trazabilidad técnica por componente.

Flujo de inspección

Selección jerárquica, hotspots, aislamiento, bottom sheet y fichas con identificación, especificaciones y datos de ensamblaje.

Análisis y modos visuales

Despiece explosivo, cortes transversales, filtros por familia funcional, lectura de fasteners reconciliados y modos técnicos como X-Ray, Solid, Blueprint y Thermal heurístico.

02

Tecnología

Unity 6

Proyecto en Unity 6000.4.3f1 con URP 17.x y build WebGL.

WebGL 2.0

Renderizado 3D en navegador sin plugins y con canvas responsive.

WebAssembly

Runtime C#/IL2CPP compilado para ejecución web.

UI Toolkit

Interfaz runtime con layout mobile-first, bottom sheet y controles modales.

Blender a Unity

Pipeline CAD-runtime con saneamiento geométrico, instancias y manifests.

Shaders HLSL

X-Ray, Solid, clipping, Blueprint, Thermal y materiales PBR adaptados a WebGL.
